# Media placeholders

Drop your photos here later:

- `career/` — pro / Katalyx / Webisport
- `vera/` — couple, nature, cinéma
- `travel/` — Tessin, Écosse, Italie, Hellfest… (`travel/{tripId}/{photoId}.jpg`)
- `sports/` — Rennes, ping-pong
- `lab/` — mycologie, éclipse, setup

Travel paths match `src` fields in `src/content/travel.ts`.
Apps currently render CSS/SVG placeholders until real files are wired in.
